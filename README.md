# Мини-платформер

Минималистичный браузерный платформер на чистом HTML/JS, без зависимостей.

## Запуск
Откройте `index.html` в любом браузере — или (рекомендуется) локальный сервер:

\`\`\`bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
\`\`\`

## Управление
- ← → или A / D — движение
- ↑ / W / Пробел — прыжок
- R — перезапуск уровня
- На мобильных — экранные кнопки

## Правила
Соберите все монеты и доберитесь до флага. Три уровня; шипы и падение сбрасывают монеты текущего уровня.
